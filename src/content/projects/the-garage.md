description: >-
  The Garage is a personal project I'm building for car owners who want to keep
  a clear record of their vehicle's history. It brings service records,
  receipts, MOT data, maintenance reminders and running costs together, with a
  shareable history for when the car changes hands. It's built as a Bun
  monorepo using React 19, Astro, TypeScript, Firebase and Cloud Functions.
